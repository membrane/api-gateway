# API Discovery Tutorial

Publish the APIs deployed on Membrane as a machine readable catalog, so that crawlers,
registries and developer portals can find them. The `apisJson` plugin builds an
[APIs.json](https://apisjson.org/) document from the running configuration, including links to
the OpenAPI documents and Swagger UIs the gateway serves.

Before you start, make sure you have completed the
[Getting Started](../getting-started) tutorial.

To begin, open [10-APIs-JSON.yaml](10-APIs-JSON.yaml) and follow the instructions in the file.
