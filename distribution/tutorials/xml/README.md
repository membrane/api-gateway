# Membrane API Gateway Tutorial - XML

This tutorial focuses on working with XML in Membrane API Gateway, including:

- XPath
- XML-to-JSON and JSON-to-XML transformations
- XML Schema validation and XSLT
- Reading, manipulating and generating XML with Groovy:
  - [70-Groovy-Read-XML.yaml](70-Groovy-Read-XML.yaml)
  - [80-Groovy-Manipulate-XML.yaml](80-Groovy-Manipulate-XML.yaml)
  - [90-Groovy-Generate-XML.yaml](90-Groovy-Generate-XML.yaml)

To begin, open [10-JSON-to-XML.yaml](10-JSON-to-XML.yaml) and follow the instructions in the file.

More examples are available in the examples folder.
