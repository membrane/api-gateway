# Scripting Tutorial

Extend Membrane with Groovy scripts when no built-in plugin covers your use case. Scripts can
read and change messages, set exchange properties and decide how the flow continues.

Before you start, make sure you have completed the
[Getting Started](../getting-started) tutorial.

To begin, open [50-Groovy-Sign-And-Verify.yaml](50-Groovy-Sign-And-Verify.yaml) and follow the
instructions in the file.
