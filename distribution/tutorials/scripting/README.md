# Scripting Tutorial

Extend Membrane with Groovy or JavaScript scripts when no built-in plugin covers your use case. Scripts can
read and change messages, set exchange properties and decide how the flow continues.

Before you start, make sure you have completed the
[Getting Started](../getting-started) tutorial.

To begin, open [10-Groovy-Builtin-Variables.yaml](10-Groovy-Builtin-Variables.yaml) and follow the
instructions in the file.

For examples of transforming messages with Groovy and JavaScript, see the
[transformation](../transformation) tutorials. For reading, manipulating and generating XML with
Groovy, see the [XML](../xml) tutorials.

Reference:

- [Built-in Variables](https://www.membrane-api.io/scripting/builtin-variables.html): variables for Groovy, JavaScript and SpEL
- [Built-in Functions](https://www.membrane-api.io/scripting/builtin-functions.html): functions for Groovy, JavaScript and SpEL
