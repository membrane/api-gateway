# 7.6.3

## Breaking Changes
- Java API (only relevant when Membrane is used as a library): `MimeType.sortMimeTypeByQualityFactorAscending(String)` is renamed to `MimeType.sortMimeTypeByQualityFactorDescending(String)`. The old name described the opposite of what the method returns. Media types with equal quality factors now keep the order the client sent them in; before, they came out in reverse client order. Callers of the old name must switch to the new one [#3348](https://github.com/membrane/api-gateway/pull/3348)
- Java API (only relevant when subclassing `AbstractXMLSchemaValidator`): `validateAgainstSchemas` and `validateWith` no longer throw `InterruptedException`, `validateWith` takes a `ValidatorPool` instead of a `BlockingQueue`, and `init()` now calls `compileSchemas()` before creating validators [#3360](https://github.com/membrane/api-gateway/pull/3360)

## Improvements
- XML Schema, WSDL and Schematron validation no longer queue behind a fixed-size validator pool under load; schemas and the Schematron XSLT are compiled once at startup instead of once per pooled validator [#3360](https://github.com/membrane/api-gateway/pull/3360)
