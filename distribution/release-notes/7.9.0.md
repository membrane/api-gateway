# 7.9.0

## Breaking Changes
- Java API (only relevant when Membrane is used as a library): the `Router` parameter is removed from `TemplateExchangeExpression.newInstance`, from the constructors of `XPathExchangeExpression` and `JsonpathExchangeExpression`, and from `Target.applyModifications`. `AbstractExchangeExpression` no longer has a `router` field; an expression that needs the router gets it from its interceptor [#TBD](https://github.com/membrane/api-gateway/pull/TBD)
