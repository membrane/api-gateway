# 6.6.5

## Fixes

### Admin console
- Values from recorded calls are escaped in the call tables, the header tables and the formatted XML view
- The body download is served as an attachment, so a recorded HTML body is not displayed as a page
- The call page accepts only a numeric exchange id

## Breaking Changes

### Admin console
- Actions that change the router, e.g. `/admin/service-proxy/save` or `/admin/node/down`, accept only POST and answer `405` otherwise. Browsers may send them only from the admin console's own pages. `node/up`, `node/down`, `node/takeout` and `node/reset` answer `404` for an unknown cluster or node. See the migration guide

### Plugins
- `clusterNotification`: `/clustermanager/up`, `/down` and `/takeout` accept only POST and answer `405` otherwise. `down` and `takeout` answer `404` for unknown nodes. See the migration guide
