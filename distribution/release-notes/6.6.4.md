# 6.6.4

## Fixes

### OpenAPI
- `minimum`, `maximum`, `exclusiveMinimum`, `exclusiveMaximum` and `multipleOf` now apply only to numbers, as in JSON Schema. Before, a string of digits, e.g. `"7"` against `maximum: 5`, was also compared with them, and every validated string was parsed as a number, which took excessive CPU time for long strings. Form fields whose schema has no `type` are strings, so these keywords no longer apply to them; declare `type: integer` or `type: number` [#3695](https://github.com/membrane/api-gateway/pull/3695)
